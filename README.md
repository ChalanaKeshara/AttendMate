# AttendMate – Student Attendance Tracker

## About the Project
AttendMate is an Android application developed to help students manage and monitor their lecture attendance easily. It provides a simple way to record attendance, manage subjects, and view attendance statistics.

## Key Features
- Add, rename, and remove subjects.
- Mark daily attendance as Present or Absent.
- Select attendance dates.
- View attendance history for each subject.
- Edit and delete attendance records.
- Monitor attendance percentages and statistics.
- Store records locally and use the app offline.

## Technologies Used
- **Programming Language:** Java
- **Development Environment:** Android Studio
- **Database:** SQLite
- **User Interface:** XML

## Project Purpose
The main purpose of AttendMate is to make student attendance management easier, more organised, and convenient through a mobile application.
